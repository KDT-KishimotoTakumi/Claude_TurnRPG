# Contract: 入力アクション

操作は Input System の Input Action アセット（`Assets/Settings/GameInput.inputactions`）に集約する。Core は入力デバイスを知らず、
Game の入力層が下表の抽象操作に変換して画面に渡す（憲法 VI）。

## アクション一覧

| アクション | 意味 | キーボード | マウス | ゲームパッド |
|-----------|------|-----------|--------|--------------|
| `Navigate` | メニュー・盤面カーソルの移動（上下左右） | 矢印キー / WASD | ポインタが指すマスや項目 | 十字キー / 左スティック |
| `Submit` | 決定（項目の選択、マスの確定、技の確定） | Enter / Space | 左クリック | A ボタン（South） |
| `Cancel` | キャンセル（1 つ戻る、予告の取り消し） | Esc / Backspace | 右クリック | B ボタン（East） |
| `EndPhase` | 味方フェーズの終了 | E | 「フェーズ終了」ボタンのクリック | Start ボタン |
| `NextTab` / `PrevTab` | 準備フェーズの画面切替 | Tab / Shift+Tab | タブのクリック | RB / LB |

## 振る舞い

- どの画面でも、上の操作だけで全機能に到達できる（FR-027）。
- 最後に操作したデバイスが有効になる。マウスを動かすとマウス操作に、ゲームパッドや
  キーボードを押すとフォーカス操作に切り替わり、選択中の項目・マスは保たれる。
- 選択中のマスは枠と色で示し、デバイスによらず同じ見た目にする（US6 シナリオ 3）。
- 接続中のデバイスが切断されても、他のデバイスで操作を継続できる。ゲームを停止しない。
- 画面の下部に操作ガイド（`HelpBar`）を日本語で常に表示する。最後に操作したデバイスに合わせて、今使える操作（例: 「A: 決定  B: 戻る」「Enter: 決定  Esc: 戻る」）を示す。
- 技の使用は「技を選ぶ → 方向（上下左右）を選ぶ → 予告を確認 → 決定」の順で、キャンセルで 1 つ前に戻る。
- ホーム画面（タイトル）の最初のフォーカスは「新しいラン」（セーブがあれば「続きから」）。

## 検証

- EditMode: アクションアセットの全アクションが 3 デバイスにバインドされていることをテストする。
- PlayMode（E2E）: 仮想の Keyboard / Mouse / Gamepad で、ラン開始から 1 戦闘の勝利までを各デバイスで完了する。
