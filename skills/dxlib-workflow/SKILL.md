# DXライブラリ 作業手順

依頼内容: $ARGUMENTS

1. **調査**: `WinMain` とメインループを見つけ、シーン管理の仕組みを確認する。
2. **設計**: 追加するクラス（シーン、キャラクターなど）と、更新・描画のどこから呼ぶかを決めて、ユーザーに伝える。
3. **実装**: `dxlib-specialist` の方針に沿って書く。
   - リソースはコンストラクタや初期化関数で読み込み、デストラクタや終了関数で解放する。
   - 新しい `.cpp` を作ったら Visual Studio のプロジェクトに追加するよう伝える。
4. **ビルド**: Visual Studio でビルドし、エラーと警告を確認する手順を伝える。
5. **確認**: 実行して動作を確認する。リソース読み込みに失敗していないか（戻り値 `-1`）も見る。
6. **レビュー**: `code-reviewer` で変更を確認する。
